# 🔊 เครื่องวัดเสียงห้องเรียน (Classroom Noise Alert)

เว็บไซต์วัดระดับเสียงแบบเรียลไทม์ผ่านไมโครโฟน เมื่อเสียงดัง **เกินขีดที่ตั้งไว้**
จะ **แจ้งเตือนอัตโนมัติ** ด้วยเสียงบี๊บ + ไฟกระพริบ + ข้อความ เหมาะสำหรับเปิดค้างไว้
หน้าห้องเรียนเพื่อเตือนให้นักเรียนไม่ส่งเสียงดัง

ทั้งหมดอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่ต้องติดตั้งอะไร และ
**ไม่มีการส่งข้อมูลเสียงออกไปที่ใดเลย** (ประมวลผลในเบราว์เซอร์ล้วน ๆ)

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (Chrome / Edge / Safari รุ่นใหม่)
   - ต้องเปิดผ่าน **https** หรือ **localhost** เบราว์เซอร์ถึงจะยอมให้ใช้ไมโครโฟน
   - เปิดไฟล์ตรง ๆ (`file://`) บางเบราว์เซอร์อาจไม่อนุญาตไมค์ — แนะนำให้เสิร์ฟผ่านเว็บ
2. กด **▶ เริ่มวัดเสียง** แล้ว **อนุญาต** ให้ใช้ไมโครโฟน
3. ปรับ **ขีดจำกัดเสียง** ให้เหมาะกับห้อง (ค่าน้อย = ไว, ค่ามาก = ต้องดังมากถึงเตือน)
4. กด **⛶ เต็มจอ** เพื่อฉายขึ้นจอหน้าห้อง

## การตั้งค่า

| ตั้งค่า | ความหมาย |
|---|---|
| **ขีดจำกัดเสียง** | ระดับเสียง (0–100) ที่เกินแล้วจะเตือน (เส้นขาวบนมิเตอร์) |
| **หน่วงเวลา** | ต้องดังต่อเนื่องกี่วินาทีถึงเตือน — กันเสียงชั่ววูบ (ไอ จาม เก้าอี้ครูด) |
| **ความไวไมโครโฟน** | เพิ่มถ้าไมค์เบา / ลดถ้าไวเกินไป |
| **เสียงแจ้งเตือน** | เปิด/ปิดเสียงบี๊บ |
| **กระพริบหน้าจอ** | เปิด/ปิดไฟกระพริบสีแดงตอนเตือน |

การตั้งค่าจะถูกจำไว้ในเครื่อง (localStorage) เปิดครั้งหน้าไม่ต้องตั้งใหม่

## เปิดใช้งานแบบเสิร์ฟผ่านเว็บ (แนะนำ)

```bash
cd noise-alert
python3 -m http.server 8000
# เปิด http://localhost:8000 ในเบราว์เซอร์
```

## หมายเหตุ

- ค่าระดับเสียงเป็นสเกลสัมพัทธ์ 0–100 (ไม่ใช่หน่วยเดซิเบลจริง เพราะไมค์แต่ละตัว
  ต่างกัน) แนะนำให้ทดลองปรับ **ขีดจำกัด** ให้พอดีกับห้องและไมค์ที่ใช้
- ควรตั้งไม่ให้เครื่อง/จอดับ ขณะเปิดค้างไว้
