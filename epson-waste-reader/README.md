# Epson Waste-Ink Reader — ตัวอ่านสถานะซับหมึก (อ่านอย่างเดียว)

เครื่องมืออ่านค่า **ตัวนับซับหมึก (waste ink pad counter)** และระดับหมึกของเครื่องพิมพ์
**Epson ที่ต่อผ่านสาย USB บน Windows** เพื่อดูว่า "ซับหมึกเต็ม" กี่เปอร์เซ็นต์แล้ว

รองรับ **Epson L3150 / L3151** และรุ่นอื่น ๆ ที่ไลบรารี `ez-reset` รองรับ

> ⚠️ **โปรแกรมนี้อ่านอย่างเดียว (READ-ONLY)** ไม่เขียน ไม่รีเซ็ต ไม่แก้ไขค่าใด ๆ
> ลงเครื่องพิมพ์ จึงไม่มีความเสี่ยงต่อฮาร์ดแวร์ ใช้แค่ดูสถานะเพื่อตัดสินใจ

---

## ทำไมต้องมีตัวนี้

เครื่อง Epson L3150 เมื่อไฟกระพริบแดง/ส้ม ปริ้นไม่ได้ และขึ้นว่า
*"Service Required / ink pads are at the end of their service life"* คืออาการ
**ซับหมึกเต็ม** — เครื่องนับปริมาณหมึกทิ้งครบเพดานแล้ว

เครื่องมือนี้ช่วยให้ **ดูตัวเลขจริง** ก่อนว่าเต็มกี่ % (ไม่ต้องเดา) แล้วค่อยตัดสินใจว่า
ถึงเวลาต้องล้าง/เปลี่ยนแผ่นซับหมึกและรีเซ็ตตัวนับหรือยัง

---

## การติดตั้ง (ครั้งเดียว)

ต้องมี **Python 3.12+** บน Windows และติดตั้งไลบรารี `ez-reset` ซึ่งเป็นตัวจัดการ
โปรโตคอล USB (IEEE-1284.4 / D4) และมีฐานข้อมูล address ของ L3150 อยู่แล้ว:

```bat
git clone https://github.com/CiRIP/ez-reset
cd ez-reset
pip install .
```

> ทำไมต้องใช้ `ez-reset`: สคริปต์นี้ **ไม่ได้เดา** ที่อยู่หน่วยความจำ (EEPROM address)
> ของเครื่องเอง แต่เรียกใช้โปรโตคอลและ address ของ L3150 ที่ชุมชนตรวจสอบแล้วจาก
> `ez-reset` ตัวเลขที่อ่านได้จึงถูกต้องจริง

---

## การใช้งาน

เสียบสาย USB เปิดเครื่องพิมพ์ แล้วรัน:

```bat
python check_waste_ink.py
```

หรือดับเบิลคลิก **`run.bat`** (ตัวช่วยสำหรับ Windows)

คำสั่งเสริม:

```bat
python check_waste_ink.py --list       :: แสดงรายชื่อเครื่องพิมพ์ USB ที่เจอ
python check_waste_ink.py --index 0    :: เลือกเครื่องพิมพ์ตามลำดับ (ถ้ามีหลายตัว)
```

## เมื่อพบว่าซับหมึกเต็ม (100%) ต้องทำอะไรต่อ

การรีเซ็ตตัวนับ (write) เป็นการ **เขียนค่าลงเครื่อง** ซึ่งอยู่นอกขอบเขตของ
เครื่องมือ "อ่านอย่างเดียว" ตัวนี้ ถ้าจะรีเซ็ตจริง ใช้ทางใดทางหนึ่ง:

1. **ez-reset GUI (ฟรี, USB):** `python -m ez_reset` → เลือกเครื่อง → ปุ่ม *Reset All*
2. **WIC Reset Utility:** โหลดจาก `wic.support` (ต้องซื้อ reset key ~$8–10)
3. **Epson Adjustment Program (AdjProg) รุ่น L3150**

> ⚠️ **สำคัญมาก:** ก่อน/หลังรีเซ็ต ควร **ล้างหรือเปลี่ยนแผ่นซับหมึกจริง** ในเครื่อง
> ไม่งั้นอีกไม่นานหมึกจะล้นออกมาเลอะข้างในหรือรั่วออกก้นเครื่อง การรีเซ็ตแค่บอกให้
> เครื่อง "นับใหม่" เท่านั้น ไม่ได้ทำให้แผ่นซับที่อิ่มหมึกแล้วว่างขึ้น

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| `ไม่พบไลบรารี ez-reset` | ยังไม่ได้ `pip install .` หรือรันบนเครื่องที่ไม่ใช่ Windows |
| `ไม่พบเครื่องพิมพ์ USB` | ตรวจสาย USB / เปิดเครื่อง / ติดตั้งไดรเวอร์ Epson แล้วหรือยัง |
| `อ่านสถานะไม่สำเร็จ` | ปิดคิวงานพิมพ์/โปรแกรมที่ยึดเครื่องพิมพ์อยู่ แล้วลองใหม่ |
