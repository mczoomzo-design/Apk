# Epson Waste Ink Tool — โปรแกรมจัดการซับหมึก Epson

โปรแกรมสำหรับเครื่องพิมพ์ **Epson ที่ต่อผ่านสาย USB บน Windows** ใช้:

- **ดู** ระดับหมึก และ % ตัวนับซับหมึก (waste ink pad counter)
- **รีเซ็ต** ตัวนับซับหมึก เมื่อขึ้น "ซับหมึกเต็ม / Service Required"

รองรับ **Epson L3150 / L3151** และรุ่นอื่นที่ไลบรารี `ez-reset` รองรับ

มี 2 แบบให้เลือกใช้:

| ไฟล์ | แบบ | มีรีเซ็ต |
|---|---|---|
| **`epson_waste_tool.py`** | โปรแกรมหน้าต่าง (GUI) — build เป็น `.exe` ได้ | ✅ |
| `check_waste_ink.py` | คำสั่งบรรทัดเดียว (CLI) | ❌ อ่านอย่างเดียว |

---

## อาการ "ซับหมึกเต็ม" คืออะไร

Epson L3150 เมื่อไฟกระพริบแดง/ส้ม ปริ้นไม่ได้ ขึ้นว่า *"Service Required / ink pads
are at the end of their service life"* คืออาการ **ซับหมึกเต็ม** — เครื่องนับปริมาณ
หมึกทิ้งครบเพดานแล้ว แก้ด้วยการ **รีเซ็ตตัวนับ** (และควรล้าง/เปลี่ยนแผ่นซับจริงด้วย)

---

## วิธีที่ง่ายที่สุด: ทำเป็นไฟล์ .exe (ดับเบิลคลิกใช้)

> ต้อง build บนเครื่อง **Windows** ที่มี **Python 3.12+** และ **Git** ติดตั้งไว้

1. ดาวน์โหลดโฟลเดอร์นี้ลงเครื่อง
2. **ดับเบิลคลิก `build_exe.bat`** — สคริปต์จะติดตั้งไลบรารีที่ต้องใช้และ build ให้อัตโนมัติ
3. ได้ไฟล์ **`dist\EpsonWasteInkTool.exe`** → ดับเบิลคลิกเปิดใช้ได้เลย (ไม่ต้องมี Python อีก)

---

## วิธีรันตรง ๆ ด้วย Python (ไม่ build)

ติดตั้งไลบรารี `ez-reset` ก่อน (ครั้งเดียว):

```bat
git clone https://github.com/CiRIP/ez-reset
cd ez-reset
pip install .
```

แล้วรัน:

```bat
python epson_waste_tool.py       :: โปรแกรมหน้าต่าง (มีปุ่มรีเซ็ต)
python check_waste_ink.py        :: แบบ CLI อ่านอย่างเดียว
```

---

## การใช้งานโปรแกรมหน้าต่าง

1. เสียบสาย USB เปิดเครื่องพิมพ์
2. เปิดโปรแกรม → เลือกเครื่องพิมพ์ในช่องด้านบน → กด **เชื่อมต่อ**
3. โปรแกรมจะแสดงระดับหมึกและ **% ตัวนับซับหมึก** (กด **รีเฟรช** เพื่ออ่านซ้ำ)
4. ถ้าซับหมึกเต็ม กด **รีเซ็ตตัวนับซับหมึก** → ยืนยันในกล่องเตือน → เสร็จแล้ว **ปิด-เปิดเครื่องพิมพ์ใหม่ 1 ครั้ง**

> ⚠️ **สำคัญมาก:** การรีเซ็ตแค่ทำให้เครื่อง "นับใหม่" **ไม่ได้ทำให้แผ่นซับหมึกจริงว่างขึ้น**
> ถ้าแผ่นซับอิ่มหมึกแล้ว ควร **ล้างหรือเปลี่ยนแผ่นซับก่อน** ไม่งั้นหมึกจะล้นออกมา
> เลอะข้างในหรือรั่วออกก้นเครื่อง

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| หน้าต่างขึ้นว่า "ไม่พบไลบรารี ez-reset" | ยังไม่ได้ `pip install .` หรือรันบนเครื่องที่ไม่ใช่ Windows |
| ไม่พบเครื่องพิมพ์ | ตรวจสาย USB / เปิดเครื่อง / ติดตั้งไดรเวอร์ Epson แล้วกด "สแกนใหม่" |
| เชื่อมต่อ/อ่านไม่สำเร็จ | ปิดคิวงานพิมพ์หรือโปรแกรมที่ยึดเครื่องพิมพ์อยู่ แล้วลองใหม่ |
| `build_exe.bat` ล้มเหลว | ตรวจว่าติดตั้ง Python (เพิ่มใน PATH) และ Git แล้ว |

## หมายเหตุด้านความปลอดภัยของข้อมูล

โปรแกรมนี้ **ไม่ได้เดา** ที่อยู่หน่วยความจำ (EEPROM address) ของเครื่องเอง แต่เรียกใช้
โปรโตคอล USB (IEEE-1284.4 / D4) และค่ารีเซ็ตของรุ่น (เช่น L3150) ที่ตรวจสอบแล้วจาก
โปรเจกต์ open-source [CiRIP/ez-reset](https://github.com/CiRIP/ez-reset) การรีเซ็ตจึง
ปลอดภัยระดับเดียวกับเครื่องมือมาตรฐานที่ใช้ ez-reset

ทางเลือกอื่นในการรีเซ็ต L3150: `python -m ez_reset` (GUI ของ ez-reset) หรือ
WIC Reset Utility (`wic.support`, ต้องซื้อ reset key)
