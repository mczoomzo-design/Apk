# Space Fleet Commander (ผู้บัญชาการกองยานอวกาศ)

เกมมือถือ Android แนว **RTS อวกาศ มุมมองด้านบน** — สร้างและบัญชาการกองยานของคุณ
สำรวจกาแล็กซี วาร์ปข้ามดวงดาว รับภารกิจ โจมตีศัตรู และบุกยึดสถานีอวกาศ

> A top-down real-time-strategy space game for Android. Build a fleet, warp across a
> galaxy of star systems, take contracts, fight varied enemy ships, and assault space
> stations. Written in Kotlin on a custom `SurfaceView` game engine — no external game
> engine, so it builds straight in Android Studio.

---

## ฟีเจอร์ในเกม (Features)

- **แผนที่กาแล็กซีแบบดวงดาว** — แต่ละระบบเป็นโหนดบนแผนที่ วาร์ปได้เฉพาะระบบที่อยู่ในระยะ
  (ลากเพื่อเลื่อน, หุบนิ้วเพื่อซูม)
- **ซื้อ/สร้างกองยานเริ่มต้นได้** ที่อู่ต่อยาน แล้วขยายกองยานได้อิสระ
- **ยาน 7 ประเภท** แต่ละแบบมีบทบาทต่างกัน:
  - `ยานลาดตระเวน (Scout)` — เบา เร็ว เซนเซอร์ไกล
  - `ยานเร็ว (Interceptor)` — ปราดเปรียว ไล่ล่ายานเล็ก
  - `ยานฟริเกต (Frigate)` — อเนกประสงค์สมดุล
  - `ยานพิฆาต (Destroyer)` — เรือรบหนัก แกนหลักกองยาน
  - `ยานประจัญบาน (Battleship)` — พลังทำลายล้างสูงสุด
  - `ยานบรรทุกเครื่องบิน (Carrier)` — ปล่อยฝูงบินขับไล่
  - `ยานยกพลขึ้นบก (Transport)` — บรรทุกพลรบไปบุกยึดสถานี
- **ติดปืนและอุปกรณ์แต่ละลำได้เอง** — เลเซอร์ / ปืนกล / พลาสมา / เรลกัน / มิสไซล์ /
  ปืนป้องกันระยะประชิด และโมดูล เช่น โล่พลังงาน เกราะ เครื่องยนต์ โรงเก็บเครื่องบิน ห้องพลรบ ฯลฯ
- **การรบแบบ RTS มุมมองด้านบน** — เลือกยาน สั่งเคลื่อนที่/โจมตี หรือใช้โหมดออโต้
- **ยานศัตรูหลายรูปแบบ** — จักรวรรดิศัตรู, โจรสลัด, สถานีป้องกัน พร้อมฝูงบินและพอยต์ดีเฟนส์
- **สถานีพันธมิตรและศัตรู** — สถานีพันธมิตรให้บริการซ่อม/ซื้อ/รับภารกิจ,
  สถานีศัตรูบุกยึดได้ด้วยยานยกพล (หรือทำลายทิ้ง)
- **ภารกิจหลายแบบ** — ลาดตระเวน, โจมตีกองยาน, บุกยึดสถานี, ล่าค่าหัว, ขนส่ง —
  เล่นแบบอิสระ (free-roam)
- **บันทึกเกมอัตโนมัติ** ลงเครื่อง (JSON) และเล่นต่อได้

## การควบคุม (Controls)

**แผนที่กาแล็กซี**
- แตะดวงดาวเพื่อเลือก → กด **วาร์ป** เพื่อเดินทาง (ถ้ามีศัตรูจะเข้าสู่การรบทันที)
- ลาก = เลื่อนแผนที่, หุบ/กางนิ้ว = ซูม
- ปุ่ม **เข้าสถานี / บุกยึดสถานี / ปรับแต่งยาน / ภารกิจ**

**การรบ (RTS)**
- แตะยานของคุณ = เลือก, แตะที่ว่าง = สั่งเคลื่อนที่, แตะศัตรู = สั่งโจมตี
- **เลือกทั้งหมด** / **ออโต้** (ให้ AI สู้เอง) / **ล่าถอย**
- ลาก = เลื่อนกล้อง, หุบนิ้ว = ซูม

## การ build เป็น APK

โปรเจกต์เป็น Android Gradle project มาตรฐาน (Kotlin) — เปิดใน **Android Studio** ได้เลย
หรือใช้บรรทัดคำสั่ง (ต้องมี Android SDK ติดตั้งและตั้งค่า `local.properties` หรือ `ANDROID_HOME`):

```bash
# debug APK
./gradlew assembleDebug
# ผลลัพธ์: app/build/outputs/apk/debug/app-debug.apk

# release APK (ยังไม่เซ็น)
./gradlew assembleRelease
```

- `minSdk` 24, `targetSdk`/`compileSdk` 34
- แนวนอน (landscape), เต็มจอ

> หมายเหตุ: ต้องมี Android SDK แยกต่างหาก (Gradle wrapper รวมมาให้แล้วในโปรเจกต์)

## โครงสร้างโค้ด (Architecture)

```
app/src/main/java/com/zoomzo/spacefleet/
├─ GameActivity.kt          # Activity เดียว โฮสต์ GameView, จัดการปุ่ม Back / fullscreen
├─ engine/                  # เอนจินกลาง (ไม่ผูกกับเนื้อเกม)
│  ├─ GameView.kt           #   SurfaceView + game loop thread + ท่าทางสัมผัส (tap/drag/pinch)
│  ├─ Game.kt               #   ตัวควบคุมสูงสุด: สเตต, สแตกหน้าจอ, toast
│  ├─ Screen.kt             #   ฐานของทุกหน้าจอ
│  ├─ Painter.kt            #   ตัวช่วยวาดบน Canvas (ไม่มีการ alloc ต่อเฟรม)
│  ├─ Camera.kt             #   กล้อง pan/zoom สำหรับสนามรบ
│  ├─ Ui.kt / Palette.kt    #   ปุ่ม/แผงUI และชุดสี
├─ model/                   # ข้อมูลเกม + การบันทึก
│  ├─ Enums / Defs / Catalog#   นิยามยาน อาวุธ โมดูล (แคตาล็อกกลาง)
│  ├─ Ship.kt               #   ยานของผู้เล่น (สเตตคำนวณจากอุปกรณ์ที่ติด)
│  ├─ Galaxy.kt             #   ระบบดาว + การสุ่มสร้างกาแล็กซี + reachability
│  ├─ Mission.kt / GameState#   ภารกิจ, เศรษฐกิจ, กองยาน, ชื่อเสียง
│  └─ SaveManager.kt        #   เซฟ/โหลด JSON
├─ combat/                  # การจำลองการรบ
│  ├─ CombatShip / Projectile / Fighter
│  └─ CombatWorld.kt        #   ฟิสิกส์ + AI + ดาเมจ + บุกยึด + ผลการรบ
└─ screens/                 # หน้าจอเกม
   ├─ MainMenuScreen, GalaxyMapScreen, StationScreen,
   ├─ ShipyardScreen, LoadoutScreen, CombatScreen, Hud
```

การรบทำงานบนเธรดของ game loop; อินพุตจาก UI thread ถูกซิงก์ด้วย `Game.lock`
เพื่อกันการชนกันของข้อมูล
