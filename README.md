# ผู้ช่วยครู AI (AI Teaching Assistant)

เว็บแอปหน้าเดียวสำหรับครู/อาจารย์ ขับเคลื่อนด้วย Claude — ไฟล์เดียวจบ ไม่ต้องติดตั้ง

## ฟีเจอร์
- 📚 **ช่วยคิดแผนการสอน** — ร่างแผนการจัดการเรียนรู้ (จุดประสงค์ K/P/A, กิจกรรม 3 ขั้น, สื่อ, การวัดผล)
- 🔬 **ช่วยคิดงานวิจัย** — เสนอหัวข้อและโครงร่างวิจัย เน้นวิจัยในชั้นเรียน
- ✅ **ช่วยตรวจงาน** — ให้คะแนนตามเกณฑ์ พร้อมจุดเด่น/จุดที่ควรปรับปรุง/ข้อเสนอแนะ
- ✏️ **ช่วยออกใบงาน/ข้อสอบ** — สร้างข้อสอบตามระดับ Bloom พร้อมเฉลยและเกณฑ์
- 📊 **ประมวลผลและตัดเกรด** — กรอกคะแนน คำนวณร้อยละ ตัดเกรด และดูสถิติทั้งห้อง (คำนวณในเครื่อง ใช้ได้แม้ไม่มี AI)
- 📝 **ช่วยสรุปการสอน** — สรุปบทเรียน ผังความคิด คำถามทบทวน และบันทึกหลังสอน

## การใช้งาน
เปิด `index.html` **ภายใน Claude (Artifact)** เพื่อใช้ฟีเจอร์ AI — ระบบจะเรียกใช้ AI ผ่านบัญชี Claude ของผู้ใช้โดยตรง (ไม่ต้องใช้ API key)

> หากเปิดไฟล์นอก Claude (เช่นบน GitHub Pages) เมนู "ประมวลผลและตัดเกรด" ยังทำงานได้ปกติ ส่วนฟีเจอร์ AI จะทำงานเมื่อเปิดใน Claude เท่านั้น

## เทคนิค
- HTML/CSS/JavaScript ล้วน ไม่มี dependency (โหลดฟอนต์จาก Google Fonts)
- ใช้ความสามารถ `sample` ของ Claude Artifact สำหรับเรียก AI
- บันทึกข้อมูลคะแนนไว้ใน `localStorage` ของเบราว์เซอร์
- รองรับโหมดสว่าง/มืด และภาษาไทย
